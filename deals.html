🇺🇸 Patriotic Card Collector — Deal Scout scans public marketplace listings to surface buying opportunities.

How we value deals: for each saved search the Scout builds a reference price from the median Buy-It-Now asking price of comparable current listings, then flags items priced well below it. Auctions appear only when they're ending soon and the current bid is still under reference. This is a market-asking proxy, not a guarantee of resale value — always read the listing, check the seller, and confirm condition and authenticity before buying. Edit watchlist.json to change what the Scout hunts for.
